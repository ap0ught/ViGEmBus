# Security Policy

## Project Status

> [!IMPORTANT]
> **ViGEmBus has reached end-of-life and is no longer actively maintained.**
> Please read the [end-of-life statement](https://docs.nefarius.at/projects/ViGEm/End-of-Life/) before reporting any issues.

## Supported Versions

No versions of ViGEmBus currently receive security updates. The project is retired and no further releases are planned.

| Version | Supported |
| ------- | --------- |
| All     | ❌ No     |

## Reporting a Vulnerability

Despite the project being retired, we still appreciate responsible disclosure of security vulnerabilities so that users can be made aware.

**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, open a [GitHub Security Advisory](../../security/advisories/new) using the private reporting feature. Provide as much detail as possible, including:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept code.
- Any suggested mitigations or fixes.

Because this project is no longer maintained, we cannot guarantee that a fix will be released. We will, however, acknowledge the report and make the advisory public so affected users are informed.
